# PebbleTape release notes
## 1.0.3 test build — October 30, 2026

- Keep the desktop sidebar and calendar, note list, and editor together.
- Open a normal window sized for Windows display scaling, without automatically maximizing.
- Apply language choices immediately and remember them; new setups follow the Windows display language.
- Show a clear error and restore the previous choice if a language setting cannot be saved.

[Download and read the installation and testing notes](https://github.com/adrovo-max/PebbleTape-showcase/releases/tag/v1.0.3).
This unsigned prerelease still needs full visual and clean-machine acceptance.

## 0.2.0 — October 4, 2026

- Record real foreground application time and review earlier days.
- Keep history and notes in an encrypted local database.
- Protect timeline viewing with a password while allowing background recording.
- Choose automatic recording at app launch or require a password first.
- Pause recording, choose private time, and keep window-title capture optional.
- Use the Windows x64 compatibility installer linked from the product page.

Navigation supports 12 languages; new recording and security text currently
supports English and Simplified Chinese with English fallback elsewhere.
Clean-PC upgrades, real lock/sleep behavior, and long-running recording still
need broader hands-on verification. See the product page for current limits.
