# Reporting a security concern

Please do not post passwords, activity records, database files, or personal
information in a public GitHub issue.

Visit [HandyPebble's contact and feedback section](https://handypebble.com/changelog/#private-feedback)
and identify PebbleTape, your app version, Windows version, and a brief
description. Do not attach private records. If a confidential report needs
additional details, wait for a reply before sharing them.

This product has not received an independent security audit. Keep Windows
updated, use separate accounts on shared PCs, and lock Windows when away.
